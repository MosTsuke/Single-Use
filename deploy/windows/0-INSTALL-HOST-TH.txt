=====================================================================
  Single-Use Sticker — ขั้นตอนติดตั้งเครื่องแม่ครั้งแรก (สำหรับฝ่าย IT)
=====================================================================

ติดตั้งที่ "เครื่องแม่" เครื่องเดียว (เครื่องที่มี SQL Server)
เครื่องอื่นในโรงพยาบาลไม่ต้องติดตั้ง — เปิด Chrome เข้าใช้ผ่าน IP ของเครื่องแม่
ใช้เวลาประมาณ 20–30 นาที · ไม่ต้องใช้อินเทอร์เน็ต


---------------------------------------------------------------------
 เตรียมก่อนเริ่ม
---------------------------------------------------------------------
  [ ] ไฟล์ singleuse-sticker-windows-....zip วางไว้ที่ Desktop ของเครื่องแม่
  [ ] สิทธิ์ admin ของเครื่องนี้
  [ ] เปิด SSMS แล้วเข้า SQL Server ด้วย sa ได้ (หรือ login ผู้ดูแลอื่น)
  [ ] ชื่อโรงพยาบาลที่จะแสดงในโปรแกรม (โลโก้ ถ้ามี — ไม่มีใส่ทีหลังได้)
  [ ] Google Chrome

  สิ่งที่โปรแกรมนี้ทำกับ SQL Server:
    สร้างฐานข้อมูลใหม่ชื่อ SingleUseSticker + login ใหม่ชื่อ singleuse_app
    ที่มีสิทธิ์เฉพาะฐานนี้ — ไม่แตะฐานข้อมูลเดิม ไม่ต้อง restart SQL Server


---------------------------------------------------------------------
 ขั้นที่ 1  แตกไฟล์
---------------------------------------------------------------------
  1. ที่ Desktop คลิกขวาไฟล์ zip > Extract All...
  2. ช่องปลายทาง ลบข้อความเดิมออก แล้วพิมพ์   C:\
  3. กด Extract

  ✔ ถูกต้อง: มีโฟลเดอร์ C:\singleuse-sticker
     ข้างในมี app, client, database, node, scripts และไฟล์ 1-start, 2-install-autostart ...
  ✘ ถ้าได้ C:\singleuse-sticker\singleuse-sticker (ซ้อนกัน) ให้ลบแล้วแตกใหม่ ปลายทาง C:\


---------------------------------------------------------------------
 ขั้นที่ 2  เช็ค SQL Server (แค่อ่าน ไม่แก้อะไร)
---------------------------------------------------------------------
  1. เปิด SSMS > เข้าด้วย sa
  2. กด New Query แล้ววาง 2 บรรทัดนี้ > กด F5

       SELECT SERVERPROPERTY('IsIntegratedSecurityOnly') AS windows_auth_only;
       EXEC xp_readerrorlog 0, 1, N'Server is listening on';

  3. ดูผล
     - windows_auth_only ต้องเป็น 0
     - ผลชุดที่สอง ดูบรรทัดที่มี  'any' <ipv4>  เลขท้ายคือ port
       ถ้ามี 1433 ให้ใช้ 1433 (เลขอื่นที่ดูสุ่ม ๆ เช่น 59798 เป็น port ชั่วคราว ไม่ต้องใช้)

     จด:  port = ____________

  ✘ ถ้า windows_auth_only = 1 หรือไม่มีบรรทัด 'any' เลย → หยุด แล้วดู README-TH.txt
     หัวข้อ "ถ้ามีปัญหา" ข้อ 1 (ต้อง restart SQL Server นอกเวลางาน)


---------------------------------------------------------------------
 ขั้นที่ 3  สร้างฐานข้อมูลใหม่ (ใน SSMS)
---------------------------------------------------------------------
  1. File > Open > File...  เลือก
       C:\singleuse-sticker\database\00_create_database.sql
  2. หาบรรทัดที่มี   CHANGE_ME_Str0ng!Pass
     เปลี่ยน CHANGE_ME_Str0ng!Pass เป็นรหัสผ่านใหม่ (เก็บ N'  ' ไว้)
       - ยาว 8 ตัวขึ้นไป มีตัวพิมพ์ใหญ่ ตัวพิมพ์เล็ก และตัวเลข
       - ห้ามมี  "  '  $  และห้ามมีช่องว่าง
  3. กด F5

  ✔ แท็บ Messages ขึ้น:
       สร้างฐานข้อมูล SingleUseSticker แล้ว
       สร้าง login singleuse_app แล้ว
       เสร็จขั้นที่ 0 ...

     จด:  รหัสผ่าน singleuse_app = ____________


---------------------------------------------------------------------
 ขั้นที่ 4  ใส่รหัสผ่านให้โปรแกรม
---------------------------------------------------------------------
  1. เปิด C:\singleuse-sticker > ดับเบิลคลิก  1-start
     (Notepad จะเปิดไฟล์ singleuse.env ขึ้นมาเอง)
  2. แก้บรรทัด   DB_PASSWORD="CHANGE_ME"
     เปลี่ยน CHANGE_ME เป็นรหัสผ่านจากขั้นที่ 3 (เก็บเครื่องหมาย " ไว้)
       ตัวอย่าง   DB_PASSWORD="Single2569Use"
  3. ถ้าขั้นที่ 2 port ไม่ใช่ 1433 → แก้บรรทัด DB_PORT=1433 เป็นเลขนั้น
  4. กด Ctrl+S > ปิด Notepad > ปิดหน้าต่างสีดำ (กดปุ่มใดก็ได้)


---------------------------------------------------------------------
 ขั้นที่ 5  เปิดโปรแกรมครั้งแรก
---------------------------------------------------------------------
  1. ดับเบิลคลิก  1-start  อีกครั้ง (มีหน้าต่างสีดำ)
  2. ถ้า Windows ถามเรื่อง firewall → กด Allow access

  ✔ หน้าต่างสีดำขึ้น:
       [db] กำลังติดตั้งโครงสร้างฐานข้อมูล 01_... 02_... 03_...
       [db] เชื่อมต่อฐานข้อมูล SingleUseSticker แล้ว — พร้อมใช้งาน

  *** อย่าเพิ่งปิดหน้าต่างสีดำ ***


---------------------------------------------------------------------
 ขั้นที่ 6  ตั้งค่าครั้งแรกในโปรแกรม (Chrome)
---------------------------------------------------------------------
  1. เปิด Chrome ไปที่   http://localhost:3002
  2. บัญชีแอดมิน: กรอกชื่อผู้ใช้ + รหัสผ่าน 2 ครั้ง > กด "สร้างบัญชีและไปขั้นถัดไป"

     จด:  ชื่อผู้ใช้แอดมิน = ____________   รหัสผ่าน = ____________

  3. กรอกชื่อโรงพยาบาล (บังคับ) · เลือกรูปโลโก้ (ไม่บังคับ)
     > กด "บันทึกและเริ่มใช้งาน"

  ✔ มุมซ้ายบนขึ้นชื่อโรงพยาบาล และมีเมนู "ผู้ดูแลระบบ"
  4. ปิดหน้าต่างสีดำได้แล้ว


---------------------------------------------------------------------
 ขั้นที่ 7  ตั้งให้เปิดเองทุกครั้งที่เปิดเครื่อง
---------------------------------------------------------------------
  1. คลิกขวา  2-install-autostart  > Run as administrator
  ✔ ขึ้นว่า "ตั้งเรียบร้อย"
  2. รอ 15 วินาที แล้วเปิด http://localhost:3002 ต้องเปิดได้ (ไม่มีหน้าต่างสีดำแล้ว)


---------------------------------------------------------------------
 ขั้นที่ 8  ให้เครื่องอื่นในแลนเข้าได้
---------------------------------------------------------------------
  1. คลิกขวา  3-open-firewall  > Run as administrator
  2. หน้าต่างจะแสดง IP ของเครื่องนี้ (บรรทัด IPv4)

     จด:  IP เครื่องแม่ = ____________

  3. ลองที่เครื่องอื่น: เปิด Chrome ไปที่   http://<IP เครื่องแม่>:3002
  แนะนำ: ล็อก IP เครื่องแม่ไว้ (static IP หรือจองใน DHCP) ไม่งั้น IP เปลี่ยนแล้วเครื่องอื่นเข้าไม่ได้


---------------------------------------------------------------------
 ขั้นที่ 9  ตั้งเครื่องแม่ไม่ให้ sleep
---------------------------------------------------------------------
  Settings > System > Power > Screen and sleep
  "When plugged in, put my device to sleep after" = Never


---------------------------------------------------------------------
 ขั้นที่ 10  ทดสอบรีสตาร์ท
---------------------------------------------------------------------
  1. Restart เครื่องแม่ (ไม่ต้อง login เข้า Windows)
  2. รอ 1–2 นาที แล้วที่เครื่องอื่นเปิด   http://<IP เครื่องแม่>:3002
  ✔ เปิดได้ = ติดตั้งเครื่องแม่เสร็จ


=====================================================================
 เสร็จแล้ว — ส่งต่อข้อมูลนี้ให้ผู้ดูแลโปรแกรม
=====================================================================
  - ที่อยู่โปรแกรม:        http://<IP เครื่องแม่>:3002
  - บัญชีแอดมินโปรแกรม:    (จากขั้นที่ 6)
  - รหัสผ่าน singleuse_app: (จากขั้นที่ 3 — เก็บไว้กับฝ่าย IT)

  ขั้นต่อไป (ไม่ใช่งานเครื่องแม่):
  - เครื่องที่ต่อเครื่องพิมพ์สติ๊กเกอร์ Godex → README-TH.txt ขั้นที่ 9 (ใช้โฟลเดอร์ client)
  - หน้างานเพิ่มรายการอุปกรณ์ / เจ้าหน้าที่ / หน่วยงาน เองที่เมนูผู้ดูแลระบบ
    (ข้อมูลเยอะใช้ปุ่ม "ไฟล์ต้นแบบ" + "นำเข้า CSV")
  - สำรองข้อมูล: โปรแกรมสำรองให้เองวันละครั้ง (ดู README-TH.txt หัวข้อ "การสำรองข้อมูล")


---------------------------------------------------------------------
 ถ้าติดปัญหา
---------------------------------------------------------------------
  หน้าต่างสีดำขึ้น "ยังไม่ได้ใส่รหัสผ่าน"
     → ทำขั้นที่ 4 ใหม่ (DB_PASSWORD ยังเป็น CHANGE_ME)
  "เข้าสู่ฐานข้อมูลไม่สำเร็จ"
     → รหัสผ่านใน singleuse.env ไม่ตรงกับขั้นที่ 3
  "เชื่อมต่อ SQL Server ไม่ได้"
     → port ใน singleuse.env ไม่ตรงกับขั้นที่ 2 หรือ SQL Server ไม่ได้เปิดอยู่
  ข้อความเกี่ยวกับ TLS / SSL / certificate
     → ใน singleuse.env แก้ DB_ENCRYPT=true เป็น DB_ENCRYPT=false แล้วเปิดใหม่
  "EADDRINUSE" (port 3002 ถูกโปรแกรมอื่นใช้)
     → ใน singleuse.env แก้ PORT=3002 เป็นเลขอื่น เช่น 3005 แล้วทำขั้นที่ 8 ใหม่
  ปัญหาอื่น ๆ
     → แคปหน้าจอ + ส่งไฟล์ C:\singleuse-sticker\logs\server.log ให้ผู้พัฒนา

  รายละเอียดทั้งหมด (อัปเดตรุ่นใหม่ ถอนการติดตั้ง ลืมรหัสแอดมิน ฯลฯ) อยู่ใน README-TH.txt
