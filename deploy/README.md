# ติดตั้งที่หน้างาน (ระบบภายใน ไม่มีอินเทอร์เน็ต)

รูปแบบ: **เครื่องแม่ 1 เครื่อง** (Windows) รันโปรแกรม + เก็บข้อมูลใน SQL Server ที่มีอยู่ในเครื่อง (ฐานข้อมูลใหม่ `SingleUseSticker`)
เครื่องอื่นในแลนเปิด Chrome ไปที่ `http://<IP เครื่องแม่>:3002` — ทุกเครื่องเห็นข้อมูลชุดเดียวกัน

## สร้างชุดติดตั้ง (เครื่องผู้พัฒนา ที่มีอินเทอร์เน็ต)

```bash
./scripts/package-windows.sh
```

ได้ไฟล์ `dist/singleuse-sticker-windows-<วันที่>-<commit>.zip` (~50 MB) ข้างในมี

| ในชุด | มาจาก | ใช้ทำอะไร |
|---|---|---|
| `app/` | Next.js standalone (`STANDALONE=1 next build`) | ตัวโปรแกรม ไม่ต้อง `npm` ที่หน้างาน · มี `app/database/*.sql` ที่โปรแกรมรันเองตอนเปิด |
| `node/node.exe` | nodejs.org (Windows x64, ตรวจ checksum) | ไม่ต้องติดตั้ง Node.js และไม่ทับตัวที่มีอยู่ |
| `database/` | `database/` | `00_create_database.sql` ให้ IT รันใน SSMS ครั้งเดียว (+ สคริปต์อื่นไว้ดู) |
| `1-start.bat` … `4-update.bat`, `stop.bat`, `uninstall.bat`, `scripts/` | `deploy/windows/` | เปิด / ตั้งเปิดเองตอนบูต (Task Scheduler) / เปิด firewall เฉพาะวงแลน / อัปเดต / หยุด / ถอน |
| `singleuse.env.example` | `deploy/windows/` | แม่แบบค่าการเชื่อมต่อฐานข้อมูล (ที่หน้างานกลายเป็น `singleuse.env`) |
| `client/` | `deploy/windows/client/` | สำหรับเครื่องที่ต่อเครื่องพิมพ์: ล็อกเครื่องพิมพ์ใน Chrome + ทางลัดเปิดแบบพิมพ์ทันที |
| `0-INSTALL-HOST-TH.txt` | `deploy/windows/0-INSTALL-HOST-TH.txt` | **ขั้นตอนสั้นสำหรับฝ่าย IT** ติดตั้งเครื่องแม่ครั้งแรก (zip อยู่ที่ Desktop) มีช่องให้จดค่า |
| `README-TH.txt` | `deploy/windows/README-TH.txt` | **คู่มือติดตั้งทีละขั้น** ตั้งแต่สร้างฐานข้อมูลจนพร้อมใช้ |

สคริปต์ไม่ยอมใส่ไฟล์ส่วนตัว (`.env.local`, `singleuse.env`, `.bak`) ลงในชุด
ส่งไฟล์ zip ไปหน้างาน (AnyDesk / USB) แล้วทำตาม `README-TH.txt`

## สรุปขั้นตอนที่หน้างาน (รายละเอียดใน README-TH.txt)

1. แตก zip ไว้ที่ `C:\singleuse-sticker`
2. เช็ค SQL Server เปิด SQL login + TCP/IP อยู่แล้ว (คำสั่งอ่านอย่างเดียว)
3. SSMS รัน `database\00_create_database.sql` (ตั้งรหัสผ่าน login `singleuse_app`) — ไม่แตะฐานข้อมูลเดิม ไม่ต้อง restart
4. `1-start.bat` → ใส่รหัสผ่านใน `singleuse.env`
5. `1-start.bat` อีกครั้ง → โปรแกรมสร้างตารางเอง → เปิด `http://localhost:3002` → ตั้งค่าครั้งแรก: สร้างบัญชีแอดมิน + ใส่โลโก้และชื่อโรงพยาบาล (บังคับทั้งสองอย่าง)
6. ฐานข้อมูลเริ่มว่าง — หน้างานกรอกรายการอุปกรณ์ เจ้าหน้าที่ หน่วยงาน เองที่เมนูผู้ดูแลระบบ
7. `2-install-autostart.bat` (admin) → เปิดเองตอนบูต
8. `3-open-firewall.bat` (admin) → เครื่องอื่นเข้าได้ (ควรล็อก IP เครื่องแม่)
9. เครื่องที่พิมพ์: ไดรเวอร์ Godex + `client\1-set-printer-Pasin2.reg` + `client\Single-Use.bat` (แก้ `APP_URL` เป็น IP เครื่องแม่)
10. ปิด sleep เครื่องแม่

อัปเดตรุ่นใหม่: วาง zip ใหม่ในโฟลเดอร์ (ไม่ต้องแตก) → `4-update.bat` (admin) — ถ้ารุ่นใหม่มีสคริปต์ฐานข้อมูลเพิ่ม โปรแกรมรันให้เองตอนเปิด

## เครื่องที่พิมพ์สติ๊กเกอร์ (โฟลเดอร์ `client/`)

เป้าหมาย: กดพิมพ์แล้วสติ๊กเกอร์ออกที่เครื่อง **Pasin 2** ทันที เจ้าหน้าที่เลือกเครื่องผิดไม่ได้

เบราว์เซอร์ไม่ยอมให้หน้าเว็บเลือกเครื่องพิมพ์เอง จึงล็อกที่ Chrome ของเครื่องนั้นแทน ด้วย 2 อย่างคู่กัน:

- นโยบาย Chrome `DefaultPrinterSelection` → เลือกเครื่องพิมพ์จากชื่อ (`1-set-printer-Pasin2.reg`)
- เปิด Chrome ด้วย `--kiosk-printing` → พิมพ์ออกทันที ไม่มีหน้าต่างให้เลือกเครื่อง (`Single-Use.bat`)

1. ติดตั้งไดรเวอร์ Godex EZ120 ตั้งชื่อเครื่องพิมพ์ใน Windows ว่า `Pasin 2`
   แล้วตั้งค่ากระดาษในไดรเวอร์เป็น **50 × 25 มม.** (โหมดนี้ไม่มีหน้าต่างพิมพ์ให้ตั้งค่า)
   ม้วนขอบเขียว **50 × 48 มม.**: เพิ่มขนาดนี้ในไดรเวอร์ด้วย · เปลี่ยนม้วนแล้ว calibrate ทุกครั้ง
   ถ้าดวงใหญ่ออกมาไม่เต็มดวง/ถูกย่อ ให้ตั้งกระดาษในไดรเวอร์เป็นขนาดของม้วนที่ใส่อยู่
2. ถ้าชื่อเครื่องไม่ใช่ `Pasin 2` ให้เปิด `1-set-printer-Pasin2.reg` ด้วย Notepad แก้ชื่อหลัง `namePattern`
   (ชื่อต้องตรงทุกตัวอักษร รวมช่องว่างและตัวพิมพ์เล็ก/ใหญ่)
3. ดับเบิลคลิก `1-set-printer-Pasin2.reg` (ต้องใช้สิทธิ์ admin)
4. เปิด `Single-Use.bat` ด้วย Notepad แก้ `APP_URL` — เครื่องแม่ใช้ `http://localhost:3002/print`
   เครื่องอื่นใช้ `http://<IP เครื่องแม่>:3002/print` แล้วสร้าง shortcut ไว้บนหน้าจอ ให้เจ้าหน้าที่เปิดจากตรงนี้เท่านั้น
5. ตรวจสอบ: เปิด Chrome พิมพ์ `chrome://policy` ต้องเห็น `DefaultPrinterSelection`
6. ในโปรแกรม หน้า พิมพ์สติ๊กเกอร์ → ⚙ ตั้งค่าเครื่องพิมพ์ → ใส่ชื่อ `Pasin 2` → **พิมพ์ทดสอบ**

ยกเลิกการล็อก: ดับเบิลคลิก `2-remove-printer-policy.reg`

### ข้อควรระวัง

- ถ้าหาเครื่อง Pasin 2 ไม่เจอ (เปลี่ยนชื่อ / ปิดเครื่อง / ถอดสาย) Chrome จะไปใช้ "บันทึกเป็น PDF" แทน
  สติ๊กเกอร์จะไม่ออก — ลองพิมพ์ทดสอบทุกครั้งหลังเปลี่ยนอะไรที่เครื่อง
  (ระบบบันทึกทันทีที่กดพิมพ์ ถ้าสติ๊กเกอร์ไม่ออกให้กด "ไม่ได้พิมพ์ – ย้อนกลับ" ภายใน 20 วินาที)
- `Single-Use.bat` ใช้โปรไฟล์ Chrome แยก (`%LOCALAPPDATA%\SingleUseKiosk`) — ข้อมูลอยู่ที่เครื่องแม่
  โปรไฟล์นี้เก็บแค่ค่าตั้งเครื่องพิมพ์ (เลื่อน X/Y) ของเครื่องนั้น
- ช่อง "ชื่อเครื่องพิมพ์" ในโปรแกรมใช้แสดงเตือนเจ้าหน้าที่เท่านั้น การล็อกจริงคือขั้นตอนข้างบน

## ทางเลือกในอนาคต

ถ้าต้องการให้โปรแกรมล็อกชื่อเครื่องเอง / เตือนทันทีเมื่อหาเครื่องไม่เจอ / แต่ละจุดใช้เครื่องคนละชื่อ
ให้ติดตั้งโปรแกรมตัวกลางสำหรับพิมพ์ (เช่น QZ Tray) แล้วให้โปรแกรมสั่งพิมพ์ผ่านตัวนั้นด้วยชื่อเครื่อง
(ต้องแก้โค้ดเพิ่ม)
