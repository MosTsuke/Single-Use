# ตั้งค่าเครื่องหน้างาน (ทำตอนติดตั้งจริง)

เป้าหมาย: กดพิมพ์แล้วสติ๊กเกอร์ออกที่เครื่อง **Pasin 2** เท่านั้น เจ้าหน้าที่เลือกเครื่องผิดไม่ได้

เบราว์เซอร์ไม่ยอมให้หน้าเว็บเลือกเครื่องพิมพ์เอง จึงล็อกที่ Chrome ของเครื่องหน้างานแทน
ด้วย 2 อย่างคู่กัน:

- นโยบาย Chrome `DefaultPrinterSelection` → เลือกเครื่องพิมพ์จากชื่อ
- เปิด Chrome ด้วย `--kiosk-printing` → พิมพ์ออกทันที ไม่มีหน้าต่างให้เลือกเครื่อง

## Windows

ไฟล์อยู่ในโฟลเดอร์ `deploy/windows`

1. ติดตั้งไดรเวอร์ Godex EZ120 ตั้งชื่อเครื่องพิมพ์ใน Windows ว่า `Pasin 2`
   แล้วตั้งค่ากระดาษในไดรเวอร์เป็น **50 × 25 มม.** (โหมดนี้ไม่มีหน้าต่างพิมพ์ให้ตั้งค่า)
2. ถ้าชื่อเครื่องไม่ใช่ `Pasin 2` ให้เปิด `1-set-printer-Pasin2.reg` ด้วย Notepad แก้ชื่อหลัง `namePattern`
   (ชื่อต้องตรงทุกตัวอักษร รวมช่องว่างและตัวพิมพ์เล็ก/ใหญ่)
3. ดับเบิลคลิก `1-set-printer-Pasin2.reg` (ต้องใช้สิทธิ์ admin)
4. เปิด `Single-Use.bat` ด้วย Notepad แก้ `APP_URL` เป็นที่อยู่จริงของโปรแกรม
   แล้วสร้าง shortcut ของไฟล์นี้ไว้บนหน้าจอ ให้เจ้าหน้าที่เปิดโปรแกรมจากตรงนี้เท่านั้น
5. ตรวจสอบ: เปิด Chrome พิมพ์ `chrome://policy` ต้องเห็น `DefaultPrinterSelection`
6. ในโปรแกรม หน้า พิมพ์สติ๊กเกอร์ → ⚙ ตั้งค่าเครื่องพิมพ์ → ใส่ชื่อ `Pasin 2` → **พิมพ์ทดสอบ**

ยกเลิกการล็อก: ดับเบิลคลิก `2-remove-printer-policy.reg`

### ข้อควรระวัง

- ถ้าหาเครื่อง Pasin 2 ไม่เจอ (เปลี่ยนชื่อ / ปิดเครื่อง / ถอดสาย) Chrome จะไปใช้ "บันทึกเป็น PDF" แทน
  สติ๊กเกอร์จะไม่ออก — ลองพิมพ์ทดสอบทุกครั้งหลังเปลี่ยนอะไรที่เครื่อง
- `Single-Use.bat` ใช้โปรไฟล์ Chrome แยก (`%LOCALAPPDATA%\SingleUseKiosk`) ข้อมูลของโปรแกรมจะอยู่ในโปรไฟล์นี้
  ให้เปิดจาก shortcut นี้ทุกครั้ง ถ้าเปิดจาก Chrome ปกติจะเห็นข้อมูลคนละชุด
- ช่อง "ชื่อเครื่องพิมพ์" ในโปรแกรมใช้แสดงเตือนเจ้าหน้าที่เท่านั้น การล็อกจริงคือขั้นตอนข้างบน

## macOS

ยังไม่ได้เตรียม — ใช้นโยบายเดียวกัน (`DefaultPrinterSelection`) ผ่าน configuration profile ของ Chrome
ทำเมื่อรู้แน่ว่าหน้างานใช้ Mac

## ทางเลือกในอนาคต

ถ้าต้องการให้โปรแกรมล็อกชื่อเครื่องเอง / เตือนทันทีเมื่อหาเครื่องไม่เจอ / แต่ละจุดใช้เครื่องคนละชื่อ
ให้ติดตั้งโปรแกรมตัวกลางสำหรับพิมพ์ (เช่น QZ Tray) แล้วให้โปรแกรมสั่งพิมพ์ผ่านตัวนั้นด้วยชื่อเครื่อง
(ต้องแก้โค้ดเพิ่ม)
