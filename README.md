# Single-Use Sticker Management

ระบบพิมพ์และติดตามสติ๊กเกอร์ Single-Use ขนาด 50 × 25 มม. สร้างด้วย Next.js, Ant Design และ TypeScript
ข้อมูลเก็บใน Microsoft SQL Server ที่เครื่องแม่ เครื่องอื่นในแลนใช้งานผ่านเว็บ (`http://<IP เครื่องแม่>:3002`)

> คนที่มาพัฒนาต่อ: อ่าน [`HANDOFF.md`](HANDOFF.md) ก่อน (สถานะงาน การตัดสินใจ และงานค้าง)

## ติดตั้งที่หน้างาน

สร้างชุดติดตั้ง Windows แบบไม่ต้องใช้อินเทอร์เน็ตที่หน้างาน:

```bash
./scripts/package-windows.sh
```

ได้ `dist/singleuse-sticker-windows-<วันที่>-<commit>.zip` แล้วทำตาม `README-TH.txt` ในชุด
(ตั้งแต่สร้างฐานข้อมูลจนพร้อมใช้ — ต้นฉบับอยู่ที่ [`deploy/windows/README-TH.txt`](deploy/windows/README-TH.txt), สรุปใน [`deploy/README.md`](deploy/README.md))

## พัฒนาในเครื่อง

ต้องมี Node.js 22 ขึ้นไป และ SQL Server (ใช้ Docker ได้):

```bash
docker run -d --name singleuse-test-sql --platform linux/amd64 -e ACCEPT_EULA=Y \
  -e 'MSSQL_SA_PASSWORD=<รหัส sa>' -e MSSQL_PID=Express -p 127.0.0.1:14333:1433 \
  mcr.microsoft.com/mssql/server:2019-latest
```

รัน `database/00_create_database.sql` (แก้ `@AppPassword` ก่อน) ด้วย SSMS / `sqlcmd` แล้วสร้าง `.env.local`:

```
DB_SERVER=127.0.0.1
DB_PORT=14333
DB_USER=singleuse_app
DB_PASSWORD="<รหัสผ่านที่ตั้งใน 00_create_database.sql>"
```

```bash
npm install
npm run dev        # โหมดพัฒนา  → http://localhost:3000 (ตารางถูกสร้างเองตอนเปิดครั้งแรก)
npm run lint       # = tsc --noEmit
```

## การตั้งค่าเครื่องพิมพ์

เครื่องพิมพ์หลัก: **Godex EZ120** (203 dpi = 8 จุด/มม., ต่อ USB)

### ตั้งค่าครั้งแรก (Godex EZ120)

1. ติดตั้งไดรเวอร์ GoDEX ของรุ่น EZ120 แล้วตั้งเป็นเครื่องพิมพ์หลัก (default)
2. ในคุณสมบัติไดรเวอร์ ตั้งขนาดกระดาษ **50 × 25 มม.** ชนิดสติ๊กเกอร์แบบมีช่องว่าง (gap)
3. ทำ calibrate เซนเซอร์กระดาษตามคู่มือเครื่อง (ทำซ้ำเมื่อเปลี่ยนม้วน)
4. ในโปรแกรม หน้า พิมพ์สติ๊กเกอร์ กดปุ่ม ⚙ **ตั้งค่าเครื่องพิมพ์** → **พิมพ์ทดสอบ**
   ถ้าข้อความไม่อยู่กลางกรอบสีส้ม ให้ปรับ **เลื่อนแนวนอน / แนวตั้ง** ทีละ 0.5 มม. แล้วพิมพ์ทดสอบซ้ำ
   (ค่าเก็บแยกตามเครื่อง ดวงทดสอบไม่ถูกบันทึกเป็นประวัติ)

บาร์โคดถูกปรับให้ 1 แท่งเล็กสุด = 2 จุดของหัวพิมพ์ 203 dpi (0.25 มม.) พอดีหัวพิมพ์ แท่งคม สแกนง่าย

### ล็อกให้พิมพ์ออกเครื่องเดียว (เช่น Pasin 2)

ดูขั้นตอนและไฟล์ที่ [`deploy/README.md`](deploy/README.md) (โฟลเดอร์ `client/` ในชุดติดตั้ง) — ทำตอนติดตั้งที่หน้างาน

### ทุกครั้งที่พิมพ์

1. กด **พิมพ์ทั้งหมด** แล้วหน้าต่างพิมพ์ของเบราว์เซอร์จะเปิดขึ้น
2. เลือกเครื่องพิมพ์ **Godex EZ120** (ถ้าติดตั้งตาม `deploy/` แล้ว จะล็อกเครื่องและพิมพ์ออกทันที ไม่ต้องเลือก)
3. ขนาดกระดาษ **50 × 25 มม.** · Margins = **None** · Scale = **100%** (Chrome จำค่าไว้ให้ครั้งถัดไป)
4. ถ้าพิมพ์หลายดวง แต่ละดวงจะขึ้นหน้าใหม่ (ดวงถัดไปบนม้วน)
5. ระบบบันทึกลงฐานข้อมูลที่เครื่องแม่ทันทีที่กดพิมพ์ ถ้าสุดท้ายไม่ได้พิมพ์ (กดยกเลิกในหน้าต่างพิมพ์) ให้กด **ไม่ได้พิมพ์ – ย้อนกลับ** ในแจ้งเตือนภายใน 20 วินาที

กรอบสีส้มพิมพ์มาจากโรงงานบนม้วนสติ๊กเกอร์ โปรแกรมพิมพ์เฉพาะเนื้อหาสีดำด้านใน

### ให้พิมพ์ออกทันทีโดยไม่ต้องกดยืนยันหน้าต่างพิมพ์

ตั้งเครื่องพิมพ์ฉลากเป็นเครื่องพิมพ์หลัก (default) แล้วเปิด Chrome ด้วย `--kiosk-printing` เช่น (macOS)

```bash
open -a "Google Chrome" --args --kiosk-printing http://localhost:3002/print
```

(Windows: เพิ่ม `--kiosk-printing` ต่อท้าย Target ของ shortcut Chrome)

## หน้า พิมพ์สติ๊กเกอร์

- ยิง SN ต่อเนื่องได้เรื่อย ๆ รายการจะสะสม แล้วกด **พิมพ์ทั้งหมด** ทีเดียว
- **วันผลิต** ตั้งแยกได้ทีละดวง ค่าเริ่มต้นคือวันนี้ (วันหมดอายุคำนวณตามรายการอุปกรณ์)
- พิมพ์รอบข้ามได้ แต่ต้องกรอกหมายเหตุ
- ต้อง **เลือกเจ้าหน้าที่ผู้พิมพ์** ก่อนพิมพ์ (ดรอปดาวน์ค้นหาชื่อ/รหัสได้) ชื่อจะพิมพ์บนสติ๊กเกอร์และบันทึกในประวัติ
  รายชื่อจัดการที่เมนู **รายชื่อเจ้าหน้าที่** (คนที่ลาออกให้ปิดใช้งาน — ลบได้เฉพาะคนที่ยังไม่เคยพิมพ์)
- ตั้งแยกได้ทีละดวง: ชนิดรหัส **บาร์โคด / QR / ไม่มี**, เปิด/ปิดบรรทัด **วันผลิต / หมดอายุ**, **ใช้ที่ (หน่วยงาน)** — ไม่บังคับ
- ชื่ออุปกรณ์ยาวพิมพ์ได้สูงสุด 2 บรรทัด เกินจะต่อด้วย "…"
- มีเสียงตอบรับ: ปี๊บสั้น = ผ่าน, ปี๊บต่ำสองครั้ง = มีปัญหา (ไม่พบ SN / ครบรอบ / ยิงซ้ำ)
- รายการที่มีปัญหาค้างไว้พร้อมปุ่มแก้ (ลงทะเบียน / ทำลาย & เปลี่ยนชิ้น) และไม่ถูกพิมพ์

## หน้าอื่น ๆ

- **แดชบอร์ด** — สรุปพิมพ์/ทำลายแยกเหตุผล ตามช่วง วัน/เดือน/ปี/ปีงบประมาณ และสถานะ ณ วันนี้ กรองรายการได้
- **อุปกรณ์รายชิ้น** — สถานะ รอบ ประวัติ · ทำลาย · ทำลายหลายรายการพร้อมกัน (แท็บรอทำลาย) · **ยกเลิกใบที่พิมพ์ผิด** (ต้องใส่เหตุผล รอบกลับเป็นรอบก่อน และบันทึกในประวัติ)
- **รายงาน** — รายวัน/เดือน/ปี/ปีงบประมาณ ส่งออก CSV (มีเจ้าหน้าที่และหน่วยงาน)

## ผู้ดูแลระบบ (แอดมิน)

- เจ้าหน้าที่ทั่วไปใช้ได้โดยไม่ต้องเข้าสู่ระบบ: พิมพ์สติ๊กเกอร์ · แดชบอร์ด · อุปกรณ์รายชิ้น · รายงาน
- เมนู **รายการอุปกรณ์ / รายชื่อเจ้าหน้าที่ / หน่วยงาน / ตั้งค่า (โลโก้และชื่อ) / บัญชีแอดมิน** เห็นเฉพาะแอดมิน (กดปุ่ม **เข้าสู่ระบบแอดมิน** ล่างซ้าย)
- ไม่มีบัญชีเริ่มต้นและไม่มีการสมัครเอง — เปิดโปรแกรมครั้งแรกหลังติดตั้ง จะขึ้นหน้า **ตั้งค่าครั้งแรก: สร้างบัญชีแอดมิน**
- แอดมินที่เข้าสู่ระบบแล้วเพิ่มบัญชีอื่นได้ที่เมนูบัญชีแอดมิน (ใช้ได้ทุกเครื่อง)
- ออกจากระบบอัตโนมัติเมื่อไม่ได้ใช้งาน 15 นาที หรือปิดหน้าต่าง
- รหัสผ่านเก็บเป็น hash (PBKDF2-SHA256 + salt) ในฐานข้อมูล ตรวจที่เครื่องแม่ และงานของแอดมินทุกอย่างเครื่องแม่ตรวจสิทธิ์ก่อนบันทึก
- ลืมรหัสผ่านทุกบัญชี: ดู `README-TH.txt` หัวข้อ "ถ้ามีปัญหา"

## ข้อมูล

- เก็บใน SQL Server ฐาน `SingleUseSticker` ที่เครื่องแม่ (แบบตาราง: [`database/README.md`](database/README.md))
- ทุกเครื่องเห็นข้อมูลชุดเดียวกัน — บันทึกจากเครื่องหนึ่ง เครื่องอื่นเห็นภายในไม่กี่วินาที
- เครื่องแม่ตรวจกฎทุกอย่างซ้ำก่อนบันทึก: ถ้า 2 เครื่องยิง SN เดียวกันพร้อมกัน เครื่องที่สองได้ข้อความแจ้ง ไม่บันทึกรอบซ้ำ
- สำรองฐานข้อมูลอัตโนมัติวันละครั้ง (เก็บ 7 วัน) ที่โฟลเดอร์ Backup ของ SQL Server
- ปุ่ม **สำรองข้อมูล** (เมนูรายการอุปกรณ์) ดาวน์โหลดข้อมูลเป็นไฟล์ JSON ได้ / **นำเข้าข้อมูล** ใช้ย้ายข้อมูลจากรุ่นทดลอง (รุ่นที่เก็บในเบราว์เซอร์) ได้เฉพาะตอนฐานข้อมูลยังว่าง
- ค่าที่ยังเก็บในเบราว์เซอร์ของแต่ละเครื่อง: ตั้งค่าเครื่องพิมพ์ (เลื่อน X/Y)

## การติดตามอุปกรณ์รายชิ้น (SN)

อุปกรณ์แต่ละชิ้นมี SN ไม่ซ้ำกัน ระบบนับรอบแยกตามชิ้น

1. **ลงทะเบียน** — เลือกประเภท แล้วให้ระบบสร้าง SN (เช่น `SUC-000001`) หรือยิง SN จากผู้ผลิต
2. **พิมพ์สติ๊กเกอร์** — ยิง SN ของชิ้นที่ sterilize เสร็จ ระบบบันทึกรอบถัดไปและพิมพ์สติ๊กเกอร์
   (SN อยู่บนบาร์โคดของสติ๊กเกอร์)
3. **ครบรอบ** — เมื่อพิมพ์รอบสุดท้ายแล้ว (เช่น 4/4) ชิ้นนั้นจะพิมพ์ต่อไม่ได้ ยิงเข้ามาระบบจะแจ้งให้ทำลาย
4. **ทำลาย & ทดแทน** — บันทึกทำลาย (ครบรอบ / ชำรุด / สูญหาย / อื่น ๆ) แล้วลงทะเบียนชิ้นใหม่ทดแทน
   ระบบจะจำว่าชิ้นใหม่มาแทน SN ไหน

สถานะของแต่ละชิ้น: ชิ้นใหม่ → ใช้งานได้ → ครบรอบ รอทำลาย → ทำลายแล้ว

- รอบสูงสุดถูกบันทึกไว้กับแต่ละชิ้นตอนลงทะเบียน แก้ค่าที่ประเภทภายหลังจะมีผลกับชิ้นใหม่เท่านั้น
- พิมพ์ซ้ำ (สติ๊กเกอร์ชำรุด): ทำได้เฉพาะดวงล่าสุดของชิ้นที่ยังไม่ถูกทำลาย ใช้ SN วันที่ และรอบเดิม ไม่นับรอบเพิ่ม
